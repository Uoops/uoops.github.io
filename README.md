# Yuanyi Ding — Personal Studio

English-language interactive personal website, with a procedural Three.js studio and an accessible reading mode.

## Hosting

Designed for GitHub Pages. Publish the `main` branch from the repository root. No build step is required.

## Editing

- `content.js`: profile, sections, and links
- `room.js`: 3D scene and lighting
- `app.js`: navigation and audio
- `styles.css`: layout and responsive styles

The current content is intentionally a first-version placeholder. The original project is maintained in the owner's local personal-site directory.
